# 🍅 โปโมโดโร Timer

แอป Pomodoro จับเวลาอัตโนมัติ ไม่ต้องกดเริ่มใหม่ทุกรอบ

## ฟีเจอร์
- เลือกเวลาทำงาน: 5 / 10 / 15 / 25 / 45 / 60 นาที
- เลือกเวลาพัก: 5 / 10 / 15 / 20 / 30 / 60 นาที
- สลับรอบอัตโนมัติ ไม่มีเสียง ไม่รอ input
- สีส้มช่วงทำงาน / สีฟ้าช่วงพัก
- เวลาถูกต้องแม้พักหน้าจอ (คำนวณจาก Date.now())

## วิธีรัน

```bash
npm install
npm run dev
```

## วิธี build

```bash
npm run build
```

ไฟล์จะอยู่ในโฟลเดอร์ `dist/` พร้อม deploy ขึ้น Vercel / Netlify / GitHub Pages
